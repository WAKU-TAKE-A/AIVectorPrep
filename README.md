# AI Vector SVG Preparation (AIVectorPrep)

画像（PowerPointスライドやモックアップ画像など）から『テキスト』と『テキスト以外』を分離抽出し、編集可能なテキストと、パーツごとに分割化された高画質な画像（PNG）で構成された**『レイヤー構造化された統合SVG』**を作成するためのツール群です。

AIエージェントによる処理自動化と、人間による確認・補正のハイブリッド処理に最適化された設計になっています。

---

## 1. 処理フローの概要

元の画像（例: `demo008.png`）を入力すると、以下の2つのレイヤーが正確な座標で重ね合わさった単一のSVGファイル（`08_final.svg`）を生成します。

```
[ 入力: ラスター画像 ] ── (本パイプライン) ──> [ 出力: 統合SVG ]
                                               ├── ① テキスト (編集可能な <text> タグ)
                                               └── ② イラスト・図形 (分割化された高画質な埋め込み <image> (PNG))
```

---

## 2. セットアップ

### 動作環境
- Python 3.10 以上
- Windows OS (PowerShell推奨)

### 2-1. 依存ライブラリのインストール
リポジトリルートで以下を実行し、仮想環境（`.venv`）を構築して必要なライブラリ（Pillow, potrace等）をインストールします。

```powershell
./setup_venv.bat
```
*(または、手動で仮想環境を作成し、`pip install -r requirements.txt` を実行)*

### 2-2. Potrace の配置
ベクター変換に使用する `potrace.exe` がリポジトリルートに配置されていることを確認してください。

## 3. 基本的な使い方と人間の役割

本ツール群は、**`scripts/step_executor.py`** というナビゲーター（実行手順管理スクリプト）に沿って、**全8ステップをAIエージェントに実行してもらう設計**になっています。

人間（ユーザー）が行う主な役割は以下の通りです。
1. **環境構築**（必要に応じてAIエージェントに依頼も可能）
2. **変換対象の画像を `Inputs/` に準備**
3. **AIエージェントを起動し、最初に `README_AI.md` を提示してルールを理解させる**
4. **二値化の条件（グレースケール方法や閾値）を提示する**
5. **進捗のコントロールと確認**:
   - 途中でAIエージェントを止め、成果物を確認しながらステップを1つずつ進めさせることも、一気に全自動で最後まで進めさせることもできます。AIエージェントとチャット対話しつつ、最終的なSVGをブラッシュアップします。

実行コマンドの基本形式（AIエージェントが実行します）

```powershell
python scripts/step_executor.py [ステップ番号(1-8)] current_working_folder.txt
```

## 4. 全8ステップのイメージ

### 【Step 1】 パス抽出（ベクター変換）
元画像から初期ベクターパスと色のメタデータを抽出します。

### 【Step 2】 テキスト領域の自動抽出
抽出したメタデータから、テキスト（文字）と思われる領域のバウンディングボックス（境界矩形）を自動計算し、視認用のナビゲーション画像を生成します。

### 【Step 3】 OCRの実行とテキストの自己補正
生成された `02_text_roi.png` をAIエージェントが目視確認し、赤枠に振られた番号ごとの文字情報を読み取ります。

### 【Step 4】 文字領域を背景色で消去
「文字である」と確定した領域のみを画像から塗りつぶし、文字のないクリーンな下敷き画像（`03_notext.png`）を生成します。

### 【Step 5】 イラストパスの再抽出
文字が消えた `03_notext.png` に対し、Step 1 と全く同じパラメータを使って、イラスト部分のみの純粋なパスを再抽出します。

### 【Step 6】 部品の自動クラスタリング
抽出したパスの密集度や重なり順から、意味のある独立したイラスト・図形部品（コンポーネント）の境界を自動計算します。

### 【Step 7】 イラスト画像の切り出し（クロップ）
自動決定した部品の境界（`06_crop_config.json`）に従って、元の美しい文字なし画像からイラスト・図形を個別のPNG画像として切り出します。

### 【Step 8】 統合SVGのビルド（最終合成）
最後に、ベースとなるSVG（キャンバス）、切り出した高画質PNGパーツ（Step 7）、およびテキストレイヤー（Step 3）を統合し、完成版のSVGを出力します。
