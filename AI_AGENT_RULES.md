# AI Agent SVG Reconstruction Rules

This document outlines the strict protocol for how the AI Agent (Antigravity) MUST process, evaluate, and reconstruct vectorized SVG images in this project.

## Workflow Pipeline

The pipeline consists of the following steps:

1. **Path Extraction (`extract_paths.py`)**
   - The CLI tool extracts paths from the input raster image using potrace.
   - It outputs files using an incremented version number (`XXX`), specifically creating `Outputs/svgsXXX/`, `Outputs/combinedXXX.svg`, `Outputs/metadataXXX.json`, and `Outputs/originalXXX.png`.

2. **AI Direct Evaluation**
   - **NO ALGORITHMIC HEURISTICS ARE ALLOWED.**
   - The AI Agent must NOT use Python scripts containing `if width < 50` or coordinate-based bounding boxes (`y < 200`) to determine if a path is text or noise.
   - The AI Agent MUST directly read `combinedXXX.svg` and `metadataXXX.json` into its context window.
   - The AI Agent uses its multi-modal vision to analyze `originalXXX.png` against the `metadataXXX.json` bounding boxes to explicitly determine which path IDs correspond to text and noise.

3. **AI Evaluation Output**
   - The AI Agent identifies a definitive list of explicitly rejected path IDs (e.g., `path_001`, `path_002`) and writes them into a targeted compilation script or updates the JSON directly with these hardcoded, AI-determined IDs.

4. **SVG Composition**
   - The AI Agent runs the composition script containing its evaluated ID list.
   - The script sets the `"accepted": false` flag for the rejected IDs and drops them.
   - The script sets `"accepted": true` for all other IDs.
   - For accepted IDs, the script samples the dominant color from the bounding box in `originalXXX.png` and assigns it as the `<path fill="...">`.
   - The script appends any custom `<text>` tags (manually defined by the AI Agent) to replace the dropped text.
   - **Crucial Rule:** The remaining graphic paths (`path***`) are NEVER modified in their geometry/coordinates (`d` attribute).
   - Finally, the script outputs `Outputs/final_coloredXXX.svg`.

## Guiding Principles
- **No Magic Numbers in Evaluation:** Path classification must rely solely on the explicit path IDs designated by the AI Agent's intelligence, not on hardcoded spatial boundaries inside evaluation scripts.
- **Maintain Geometry:** The AI Agent and its output scripts must preserve the geometric integrity of the SVG paths generated by `extract_paths.py`.
